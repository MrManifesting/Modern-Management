## 2025-06-13 - Search Keyboard Shortcut & Discoverability
**Learning:** Adding a keyboard shortcut (Cmd+K) to the global search improves navigation efficiency for power users, while a visual hint (<kbd>) ensures discoverability for all users.
**Action:** Always include responsive padding on inputs with absolute-positioned hints (like <kbd>) to prevent text overlap, and use `sr-only` or `aria-label` for screen reader accessibility.
